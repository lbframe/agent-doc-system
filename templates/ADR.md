# Architecture Decision Records

One file per decision: `NNNN-short-title.md`. An ADR records a decision and its
consequences, and is immutable once accepted — supersede it with a new ADR that
links back.

## Template

    # NNNN. Short title in one imperative sentence

    ## Status
    proposed | accepted | superseded by NNNN

    ## Context
    What was true before this decision. Facts, with evidence.

    ## Decision
    What was decided, in one sentence.

    ## Consequences
    What becomes easier, what becomes harder, and what is now forbidden.

    ## Evidence class of each claim
    Which parts are authored intent, which are derived from code, and which
    were observed in a running system. Disagreement between them is the point
    of this section, not a flaw in it.
