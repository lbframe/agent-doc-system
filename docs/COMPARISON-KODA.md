# Koda comparison

Reference: the Koda production repository (private) at `origin/main` =
`19b2227f17d0116ef5e8d8a6dd1e86ff1fdb913b`.
The portable system was run against a working copy of that commit. No Koda source,
configuration or production behaviour was modified.

This file is generated by `scripts/compare-koda.py`; every number in the tables
below is computed from the two graphs. Prose figures that describe a fixed past
event — how many duplicates an earlier run emitted, how many rows of noise a
misconfiguration produced — are historical, and are marked as such.

**Two bases are used, and they are not interchangeable.** *Triples* are
`(type, source, target)` — the architecture-level fact. *Relations* are individual
emitted edges, which outnumber triples wherever one fact is deliberately several
edges: a scheduler pointing at four routes of one API is four relations and one
triple. The comparison table is on triples; the relation totals are given
separately and are stated as relations.

**Relation names are normalised before comparison.** The reference prefixes every
relation with the product namespace (`koda-build-depends-on`); the portable system
uses neutral names (`buildDependsOn`). Without that normalisation the shared count
is 44% rather than 84%.

## What was not reproduced, and why

The 38 reference triples absent from the portable graph, grouped by cause:

1. **10 resource edges** (`usesResource`/`resourceUsedBy` and their inverses). The
   reference resolves a component to a logical dataset from a bucket literal plus a
   name token. The portable system reports `AGENTDOC_BINDING_AMBIGUOUS` instead,
   because several authored `logical-dataset` Resources match one object-store client
   and no deterministic rule separates them. The information is surfaced for review
   rather than guessed. This is a deliberate difference, not a regression: the
   reference's heuristic is exactly the kind of inference the authority model forbids
   from becoming a fact, and the ambiguity is what produces the 7 unresolved
   `resource.ownership` conflicts above.
2. **6 API-consumer edges** (`consumesApi`/`apiConsumedBy`). Some are declared as
   `reviewedOverrides` in the reference configuration that were not ported for this
   comparison; the rest were derived by a reference-specific rule. The split is not
   stated as a count because the reference graph records no marker distinguishing a
   reviewed override from a derived edge, so the number is not recoverable from the
   artefact and would be a guess presented as a measurement.
3. **1 schedule edge and 1 runtime call**: one unreviewed override, and one
   route-owner tie that ranked resolution declines to break.
4. **1 build edge** derived by a reference-specific devDependency rule.

The portable graph additionally contains 14 triples the reference does not,
principally TypeScript workspace edges derived from `package.json` dependencies,
which the reference does not record.

## Defects found by running against the real repository

Each of these was found by running against Koda rather than against a fixture, and
fixed in the engine rather than in a threshold.

1. **Duplicate relations.** The first run emitted 14 relations twice — the same fact
   once per adapter that noticed it — because the derivation tag `via` was part of a
   relation's identity. A `consumesApi` edge asserted by both a reviewed override and
   a source reference appeared twice, with the override's provenance hidden behind a
   derived edge with identical endpoints. `via` is now excluded from identity and the
   derivation routes merge into a sorted list.
   Two follow-on defects of the same kind were found while fixing this: the merge
   *relabelled* a corroborated override as `AUTHORED`, so the graph understated its own
   highest-authority input; and a mechanism route and a declared-client route to one
   Resource still shipped as two edges. Both are fixed.
2. A flow-mapping scalar containing a comma — `{ description: Body is bad, invalid, or wrong. }` —
   was rejected. Real OpenAPI documents contain these and the ecosystem parses them.
   The flow parser now matches that behaviour deterministically.
3. A Go workspace member depended on only by import, with no `require` line, was
   invisible: the import pattern required three dots and Go module paths have two.
4. A repository path was resolved against the process working directory, so the same
   commit compiled differently depending on where the compiler ran.
5. A task-graph command was emitted for a component that does not declare the task,
   putting an unrunnable command in front of an agent as if it were the answer.
6. Every third-party package was recorded as an external dependency — 602 rows of
   noise. External-service classification is now declared, and an unclassified count
   is reported for a human to triage.
7. A command carrying a credential as a separate argument (`curl -u user:pass`)
   reached the graph verbatim. Redaction and the output scanner now cover it.

## Requirements the portable system adds

- Every `Resource` must state its placement (`system` or `placementRationale`). The
  reference allowed a resource with no owner statement; the portable system treats
  that as the ambiguity it is. Cost: one line per resource.
- Capability detectors and external-service classification are declared in
  configuration rather than hard-coded in an extractor.
- Reviewed overrides must state the condition under which they are re-examined, and
  the digests of the evidence they cite are re-verified on every compile.
- Observations, facts, conflicts and contract pointers are new surfaces with no
  reference equivalent.

## Verdict

All 53 entities, all 46 placement edges, all 10 API provider edges and the journey
are preserved exactly. 196 of 234 relation triples (84%) are identical. Every missing
edge is accounted for above, and in each case the portable system declines to guess
rather than assert something the repository does not state. No information was
silently lost: unresolved bindings surface as diagnostics carrying the evidence that
would settle them.

**No blocking regression.** The seven defects above were fixed in the engine.
